# Fragment: Observation

## Instructions

1. Read the active mission, relevant project instructions, and current files.
2. Inspect only evidence that can change action selection or validation.
3. Prefer direct sources over summaries and distinguish current facts from historical context.
4. Check actual effects before repeating interrupted or uncertain work.
5. Stop gathering when there is enough evidence for a safe next action.

## Output

- Relevant known facts and sources
- Changed or missing context
- Evidence gaps that matter now
