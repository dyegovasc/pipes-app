# Fragment: Execution

## Instructions

1. Perform the selected action in its canonical location.
2. For generated project artifacts, apply `rule-artifact-record-contract`. Carry explicit sources and the invoking mission into the complete creation procedure. Verify reciprocity with the app open or closed. Preserve managed metadata during regeneration.
3. Preserve unrelated user work and avoid opportunistic scope expansion.
4. Keep only a concise factual account of changed files, artifacts, commands, and deviations.
5. Before repeating an interrupted or externally visible action, inspect whether it already happened.
6. Continue through coherent safe follow-up work until validation or a real stop condition is reached.

## Output

- Changes or observations produced
- Execution evidence
- Deviations, blockers, or protected next action
