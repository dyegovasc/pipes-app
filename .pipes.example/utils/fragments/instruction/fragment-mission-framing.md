# Fragment: Mission Framing

## Instructions

1. State one concrete objective in outcome language.
2. Name what is in scope and explicitly out of scope.
3. Record constraints and protected actions that require the user.
4. Identify the primary role and only the consultations likely to matter.
5. Define observable validation and the four real stop conditions: complete, user decision, blocker, or protected action.
6. Ask only for missing information that materially changes this frame.

## Output

- Objective
- Scope
- Operating envelope
- Roles
- Validation expectations
- Stop conditions
