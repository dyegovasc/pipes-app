# Rule: Question Options Format

## Requirement

When choices help, present a short set of mutually exclusive options in plain language and preserve a free-form answer path.

## Checks

- Ask only when the choice materially changes the result.
- Use stable short labels or keys when an answer must be reused later.
- Explain the practical trade-off of each option.
- Avoid exhaustive questionnaires and multi-step approval forms.
- Do not turn a selection into a durable decision without the required authority.
