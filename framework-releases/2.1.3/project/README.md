# Project Records

Project records are concise Markdown memory. Create them only when the content will help future work.

| Area | Purpose |
| --- | --- |
| `00-notes/` | Research, source material, and exploratory thinking |
| `01-objectives/` | Stable desired outcomes |
| `02-missions/` | Concrete adaptive loop runs |
| `03-plans/` | Bounded executable specifications |
| `04-decisions/` | Durable choices and rejected alternatives |
| `05-outcomes/` | Factual closure and residual risk |
| `06-artifacts/` | Supporting evidence, exports, and generated assets |

All records use readable paths for relationships. Area `config.md` files define the small frontmatter contract for their records.
